# Skill lessons

One entry per gap found in a skill. These are generalized into the framework at the end of the project.

## Entry format

```
### YYYY-MM-DD · <skill> v<version> · step <n>
- Compared: skill vs <designer blind review | user choice | user findings | developer question>
- Gap: what the skill missed or got wrong
- Fix: what changed in the skill
- Generalized lesson (no project facts): ...
```
